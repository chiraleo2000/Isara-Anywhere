# 🚀 Quick Start Guide - IZARA HTML Presentations

## Open the Presentations

### Method 1: Double-Click (Easiest)
```
📂 Navigate to: Presentations/html-presentations/
🖱️ Double-click: index.html
```

### Method 2: From Browser
```
File → Open File → Navigate to html-presentations/index.html
```

### Method 3: Command Line
```powershell
# Windows
cd "c:\Users\chira\Documents\Isara-telemed\Isara-anywhere-V0.0.2\Presentations\html-presentations"
start index.html

# Or using PowerShell
Start-Process ".\index.html"
```

## ⌨️ Keyboard Shortcuts

- **F11** - Toggle fullscreen (presentation mode)
- **Ctrl + +/-** - Zoom in/out
- **Ctrl + 0** - Reset zoom
- **Alt + ←** - Browser back
- **Alt + →** - Browser forward
- **Ctrl + R** - Refresh page

## 🎯 Presentation Tips

### Before Presenting
✅ Open index.html and pre-load all needed presentations  
✅ Check internet connection (for Mermaid.js)  
✅ Test fullscreen mode (F11)  
✅ Close unnecessary browser tabs  
✅ Set display resolution to 1920x1080 or higher  

### During Presentation
✅ Use fullscreen mode (F11)  
✅ Navigate with on-screen buttons  
✅ Use Home button to return to index  
✅ Keep mouse cursor visible for navigation  

### After Presentation
✅ Exit fullscreen (F11 or Esc)  
✅ Can save as PDF: File → Print → Save as PDF  

## 🔄 Regenerate All Files

If you modify the original `.mmd` diagram files:

```powershell
cd Presentations
.\generate-html-presentations.ps1
```

This will regenerate all HTML files while preserving the index.html.

## 🆘 Troubleshooting

**Diagrams not showing?**
→ Check internet connection (Mermaid.js loads from CDN)

**Layout broken?**
→ Try Ctrl+F5 (hard refresh)

**Text too small?**
→ Use Ctrl + + to zoom in

**Navigation not working?**
→ Ensure JavaScript is enabled in browser
