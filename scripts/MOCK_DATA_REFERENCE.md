## Scripts Reference

### Primary Test Scripts

| Script | Purpose |
|--------|---------|
| `runFullTestCycle.cjs` | Master orchestration - runs complete CI/CD cycle |
| `cleanDatabase.cjs` | Removes all data from GCS buckets |
| `generateComprehensiveMockData.cjs` | Creates all mock users and clinical data |
| `comprehensiveSeleniumTests.cjs` | Runs 53 Selenium UI/API/Backend tests |

### Running the Full Test Cycle

```bash
# Full cycle (clean → generate → test)
node scripts/runFullTestCycle.cjs

# With options
node scripts/runFullTestCycle.cjs --headless --max-retries 3

# Skip cleaning (use existing data)
node scripts/runFullTestCycle.cjs --skip-clean

# Skip data generation
node scripts/runFullTestCycle.cjs --skip-generate

# Export final data
node scripts/runFullTestCycle.cjs --export
```
