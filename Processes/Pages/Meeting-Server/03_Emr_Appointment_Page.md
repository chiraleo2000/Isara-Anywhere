# EMR Appointment Page — Post-Meeting Documentation

**Component:** `EmrAppointmentPage.tsx`
**Route:** `/doctor/:userId/emr/:appointmentId`
**Thai Title:** บันทึก EMR ตามนัดหมาย

## Purpose

Loads patient context from appointment ID and opens `CompleteEMREditor`, applying `emr-ai-draft` from sessionStorage after meeting validation (man-in-the-loop).

## Workflow

```text
MeetingResults validate → sessionStorage emr-ai-draft → EmrAppointmentPage → CompleteEMREditor → sign EMR
```
