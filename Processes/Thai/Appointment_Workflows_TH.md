# ขั้นตอนการนัดหมาย Izara Telemedicine

เอกสารนี้อธิบายขั้นตอนการนัดหมายทั้งหมดของ Izara Telemedicine ครอบคลุมการปรึกษาผ่านวิดีโอ การทำเอกสาร EMR และฟีเจอร์หลังการปรึกษาที่ AI ช่วยเหลือ

**อัปเดตล่าสุด:** 21 มกราคม 2569 (v3.0.0 - Phase 1 เสร็จสมบูรณ์)

### การเข้าถึงแขกภายนอก (ผู้ใช้ที่ไม่ได้ลงทะเบียน) ✅

แขกภายนอกที่ **ไม่ได้ลงทะเบียน** ในระบบ Izara สามารถเข้าร่วมประชุมได้:

| ประเภทแขก | ใครเชิญได้ | ตัวอย่างอีเมล |
| ------------ | ---------------- | ---------------- |
| ญาติผู้ป่วย | ผู้ป่วย | <mother@gmail.com>, <father@hotmail.com> |
| คู่ครองผู้ป่วย | ผู้ป่วย | <spouse@outlook.com> |
| แพทย์เฉพาะทาง | แพทย์ | <dr.cardio@privatehospital.co.th> |
| ที่ปรึกษาแพทย์ | แพทย์ | <professor@university.ac.th> |
| อื่นๆ | ทั้งสอง | <any.guest@anydomain.xyz> |



## วิธีที่แขกภายนอกเข้าร่วม:
1. แพทย์/ผู้ป่วยสร้างการเชิญ → ระบบสร้าง Token ที่ปลอดภัย
2. แขกได้รับ URL เชิญ (ผ่านอีเมลหรือลิงก์ที่แชร์)
3. แขกคลิกลิงก์ → ไม่ต้องเข้าสู่ระบบ
4. แขกเข้าห้องรอ → แพทย์อนุมัติ
5. แขกเข้าร่วมประชุมพร้อมวิดีโอ/เสียง เปิด

## สรุป

ระบบนัดหมาย Izara Telemedicine ครบวงจร:

1. **ผู้ป่วยจอง** → รอแพทย์ยืนยัน
2. **แพทย์ยืนยัน** → สร้างลิงก์ประชุม + แจ้งผู้ป่วย
3. **ประชุมออนไลน์** → แพทย์เป็น HOST + ห้องรอ + บันทึก + ถอดเสียง
4. **AI ประมวลผล** → สร้าง EMR Draft + คำแนะนำผู้ป่วย
5. **แพทย์ตรวจสอบ** → Man-in-the-Loop อนุมัติ
6. **ผู้ป่วยรับเอกสาร** → ดูสรุปและคำแนะนำในพอร์ทัล
