# การประชุมวิดีโอ - Jitsi Meet + Device Speech-to-Text + Gemini AI

**เวอร์ชัน:** 3.0.0
**อัปเดตล่าสุด:** 21 มกราคม 2569
**สถานะ:** ✅ Phase 1 ใช้งานเสร็จสมบูรณ์

---


## ภาพรวม

เอกสารนี้อธิบายการใช้งานการประชุมวิดีโอโดยใช้:


- **Jitsi Meet** (ฟรี) สำหรับการประชุมวิดีโอพร้อมระบบห้องรอ

- **Device/Browser Speech-to-Text** (ฟรี) สำหรับการถอดเสียงแบบ Realtime ระหว่างประชุม

- **Gemini 2.5 Flash AI** สำหรับสรุป EMR, สรุปก่อนพบแพทย์ และคำแนะนำผู้ป่วย

- **PostgreSQL** สำหรับจัดเก็บ transcript, สรุป และ metadata การประชุม

---


## ฟีเจอร์หลัก


### 1. แพทย์เป็น Meeting HOST


- **แพทย์เท่านั้นที่สามารถเริ่มการประชุม** - แพทย์ทำหน้าที่เป็นผู้ดำเนินการ/host

- แพทย์ควบคุมการอนุมัติเข้าห้องรอ, การบันทึก และการตั้งค่าประชุม

- แพทย์ได้รับลิงก์ประชุมในตารางนัดหมาย/ปฏิทิน


### 2. ระบบห้องรอสำหรับอนุมัติแขก


- **ผู้ป่วยรอในห้องรอ** จนกว่าแพทย์จะเข้าร่วมและอนุมัติ

- **ญาติผู้ป่วย** สามารถเชิญผ่านอีเมลและต้องได้รับการอนุมัติจากแพทย์

- **ที่ปรึกษาแพทย์/ผู้เชี่ยวชาญ** สามารถเชิญและต้องได้รับการอนุมัติจากแพทย์

- ห้องรอป้องกันการเข้าถึงการปรึกษาโดยไม่ได้รับอนุญาต


### 3. ระบบเชิญแขก


- **การเชิญแบบ Token-based** สร้างสำหรับแขกแต่ละคน

- ส่งการเชิญผ่านอีเมลพร้อมลิงก์เข้าร่วมเฉพาะ

- ประเภทการเชิญ: `patient_relative`, `doctor_consultant`, `family_member`

- แพทย์สามารถยกเลิกการเชิญได้ตลอดเวลา


### 4. การควบคุมสื่อ (ค่าเริ่มต้น: เปิด)

| การควบคุม | ค่าเริ่มต้น | หมายเหตุ |
| -------- | --------- | ------- |
| **กล้อง** | เปิด | `startWithVideoMuted=false` |
| **ไมโครโฟน** | เปิด | `startWithAudioMuted=false` |
| **แชทข้อความ** | เปิด | ใช้งานได้ตลอด |


ผู้ใช้สามารถปิด/เปิดเสียงได้ตลอดเวลา


### 5. การถอดเสียงแบบ Realtime (ฟีเจอร์ Phase 1)


- **Device/Browser Speech-to-Text API** (ฟรี - ไม่มีค่าใช้จ่าย Google Cloud)

- การถอดเสียงแบบ Realtime ระหว่างการประชุม

- Transcript บันทึกลงตาราง PostgreSQL `meeting_transcripts`

- รองรับภาษาไทยและอังกฤษ


### 6. การสร้าง EMR ด้วย AI พร้อม Man-in-the-Loop


- **Gemini 2.5 Flash** ประมวลผล transcript การประชุมทั้งหมด

- สร้าง EMR draft รูปแบบ SOAP

- **แพทย์ต้องตรวจสอบ** ก่อนบันทึก (Man-in-the-Loop)

- แพทย์สามารถแก้ไข, อนุมัติ หรือให้สร้างใหม่


### 7. การสร้างเอกสารคำแนะนำผู้ป่วย


- AI สร้างสรุปที่เข้าใจง่ายสำหรับผู้ป่วยจาก EMR

- รวมคำอธิบายการวินิจฉัย, คำแนะนำการใช้ยา, อาการเตือน

- แพทย์ตรวจสอบก่อนส่งถึงผู้ป่วย

- ผู้ป่วยดูในพอร์ทัลผู้ป่วยภายใต้ประวัติสุขภาพ

### การตรวจจับภาษาอัตโนมัติ

```javascript
const recognition = new webkitSpeechRecognition();
recognition.continuous = true;
recognition.interimResults = true;
recognition.lang = 'th-TH'; // ภาษาหลัก

// สลับภาษาอัตโนมัติตามเนื้อหา
recognition.onresult = (event) => {
  const transcript = event.results[event.results.length - 1][0].transcript;
  const detectedLang = detectLanguage(transcript); // th หรือ en
  saveTranscript(transcript, detectedLang);
};
```
